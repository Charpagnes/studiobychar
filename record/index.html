Podcast questions

What equipment is included in the podcast studio?

Each set includes a multi-camera rig (up to 3 angles), professional condenser microphones, lighting and a sound-treated room. Every set is pre-configured and ready to record.

Can I use the podcast studio without a technician?

Yes, you can run the session yourself. We recommend the on-site technician for first-timers or bigger setups, so you can focus on the conversation.

Which podcast set should I choose?

Set A is wicker and warm, good for lifestyle and wellness. Set B is clean and minimal, good for business content and tutorials. Set C is the velvet sofa, good for brand interviews and storytelling. Set D is bold and editorial, good for creators who want the set to be part of the brand.

What is the difference between booking by the hour and a monthly plan?

Hourly booking is pay and go: pick a slot and record. Monthly plans (Podcast Pro, YouTube Growth and Studio Bundle) start with a 20-minute discovery call so we can shape the plan around your show.

Can you edit my episodes?

Yes. Post-production editing is available on request. Send us a brief and we'll sort it.
